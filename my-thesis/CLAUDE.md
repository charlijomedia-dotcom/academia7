# My Thesis

Project instructions for Claude.

## Structure
- `approved-specs/part1..part5/` – approved specifications for each thesis part
- `data/` – raw and processed data
- `code/` – analysis and processing code
- `output/` – generated results (figures, tables)
- `reports/` – written reports and drafts
- `notes/` – working notes

## Conventions
- Follow the approved specs in `approved-specs/` before making changes.
- Keep generated files in `output/`, never in `code/`.
